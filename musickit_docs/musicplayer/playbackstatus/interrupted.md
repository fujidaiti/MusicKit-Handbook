# MusicPlayer.PlaybackStatus.interrupted

The music player is in an interrupted state, such as from an incoming phone call.

iOS 15.0+iPadOS 15.0+Mac Catalyst 15.0+macOS 14.0+tvOS 15.0+visionOS 1.0+

```
case interrupted
```

## [Discussion](/documentation/musickit/musicplayer/playbackstatus/interrupted#discussion)

When an incoming phone call interrupts the music player, it may resume playing
automatically upon ending the call.
