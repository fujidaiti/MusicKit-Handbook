# contentRating

The rating of the content.

iOS 16.0+iPadOS 16.0+Mac Catalyst 16.0+macOS 13.0+tvOS 16.0+visionOS 1.0+watchOS 9.0+

```
var contentRating: ContentRating? { get }
```

## [Discussion](/documentation/musickit/playlist/entry/item-swift.enum/contentrating#discussion)

A nil value means no rating is available for this playlist entry’s item.
