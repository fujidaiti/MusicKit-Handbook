# episodeNumber

The episode number of the station.

iOS 15.0+iPadOS 15.0+Mac Catalyst 15.0+macOS 12.0+tvOS 15.0+visionOS 1.0+watchOS 8.0+

```
var episodeNumber: Int? { get }
```

## [Discussion](/documentation/musickit/station/episodenumber#discussion)

This value appears when the station represents an episode of a show or other
content.
