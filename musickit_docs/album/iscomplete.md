# isComplete

A Boolean value that indicates whether the album is complete.

iOS 15.0+iPadOS 15.0+Mac Catalyst 15.0+macOS 12.0+tvOS 15.0+visionOS 1.0+watchOS 8.0+

```
var isComplete: Bool? { get }
```

## [Discussion](/documentation/musickit/album/iscomplete#discussion)

If true, the album is complete; otherwise, it’s incomplete. An album is complete
if it contains all its tracks and songs.
