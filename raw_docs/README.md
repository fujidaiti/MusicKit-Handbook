# Apple MusicKit Documentation

This documentation was scraped from [Apple Developer Documentation](https://developer.apple.com/documentation/musickit). It contains 929 pages and each HTML page was converted to a markdown file. The original page structure is preserved as much as possible, for example, the page at "developer.apple.com/documentation/musickit/musicpersonalrecommendationsrequest/init()" is stored in "<root>/musicpersonalrecommendationsrequest/init().md". The entry point is "<root>/index.md" and you can follow local links in it to explore the other pages.
