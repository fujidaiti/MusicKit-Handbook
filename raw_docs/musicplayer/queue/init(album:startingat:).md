# init(album:startingAt:)

Creates a playback queue with an album and a specific track for the player to start playback.

iOS 16.4+iPadOS 16.4+Mac Catalyst 16.4+macOS 14.0+tvOS 16.4+visionOS 1.0+

```
required init(
    album: Album,
    startingAt startTrack: Track
)
```
