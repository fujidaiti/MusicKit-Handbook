# pause()

Pauses playback of the current entry.

iOS 15.0+iPadOS 15.0+Mac Catalyst 15.0+macOS 14.0+tvOS 15.0+visionOS 1.0+

```
func pause()
```

## [Discussion](/documentation/musickit/musicplayer/pause()#discussion)

If playback isn’t currently underway, this method has no effect. To resume
playback of the current entry from the pause point, call the
[`play()`](/documentation/musickit/musicplayer/play()) method.
