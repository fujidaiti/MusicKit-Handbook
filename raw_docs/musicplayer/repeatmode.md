# MusicPlayer.RepeatMode

The repeat modes for the music player.

iOS 15.0+iPadOS 15.0+Mac Catalyst 15.0+macOS 14.0+tvOS 15.0+visionOS 1.0+

```
enum RepeatMode
```

[`case none`](/documentation/musickit/musicplayer/repeatmode/none)

[`case one`](/documentation/musickit/musicplayer/repeatmode/one)
