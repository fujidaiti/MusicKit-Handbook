# isAppleDigitalMaster

A Boolean value that indicates whether the album is an Apple Digital Master.

iOS 16.0+iPadOS 16.0+Mac Catalyst 16.0+macOS 13.0+tvOS 16.0+visionOS 1.0+watchOS 9.0+

```
var isAppleDigitalMaster: Bool? { get }
```

## [Discussion](/documentation/musickit/album/isappledigitalmaster#discussion)

Apple Digital Masters start from 24-bit files and are optimized to bring the
best-sounding audio to Apple products.
