# init(playlist:startingAt:)

Creates a playback queue with a playlist and a specific playlist entry for the player to start playback.

iOS 16.4+iPadOS 16.4+Mac Catalyst 16.4+macOS 14.0+tvOS 16.4+visionOS 1.0+

```
required init(
    playlist: Playlist,
    startingAt startPlaylistEntry: Playlist.Entry
)
```
